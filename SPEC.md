# Спецификация: «Собери рюкзак»

Документ для продолжения работы над проектом в новой сессии. Он описывает текущее состояние, а не историю. Состояние на 22.11.2026.

## 1. Назначение

Ученица 5 класса музыкального колледжа в Минске (класс 5А фс, фортепиано) забывает вещи в школу. Приложение показывает, что собрать к выбранному дню. Пользуется она с iPhone. Заказчик и владелец проекта — её отец; он не инженер.

Проблема, которую решает приложение, — момент и список, а не мотивация. Триггером служит вечернее напоминание в Apple Reminders.

## 2. Как устроено

- Одностраничное веб-приложение без сервера и без сборки. Чистые HTML, CSS, JavaScript.
- Размещение: GitHub Pages, публичный репозиторий `iChuvak/shadowmilk`, ветка `main`, корень.
- На iPhone устанавливается через Add to Home Screen и работает без интернета.

Файлы:

| Файл | Назначение |
|---|---|
| `index.html` | Вся разметка, стили, логика и данные |
| `sw.js` | Работа офлайн: сеть в приоритете, при отсутствии сети сохранённая копия |
| `manifest.webmanifest` | Имя, иконки, режим отдельного окна |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | Значок: рюкзак с лицом, собственный рисунок |

Внешняя зависимость одна: шрифты Google Fonts (Manrope, Unbounded). Без сети подставляются системные.

## 3. Данные

### В коде (источник правды)

- `SCHEDULE` — расписание: день 1–6 → `[номер урока, ключ предмета, кабинет]`.
- `NAMES` — названия предметов по ключу.
- `DEFAULTS.always`, `DEFAULTS.subj`, `DEFAULTS.papa` — списки вещей.
- `TIMES`, `ENDS` — начало и конец уроков 1–7.

Списки вещей читаются только из кода. Изменение доходит до телефона через `git push`.

### В телефоне (localStorage, ключ `ryukzak-v1`)

- `extras` — «Особое на день»: `{id, day, text, date}`. `date` задан у разовой вещи и пуст у еженедельной.
- `checks` — галочки и ответы по датам: `{ "ГГГГ-ММ-ДД": { ключ: true } }`.

Ключи в `checks`: `a:текст` (каждый день), `s:предмет:текст`, `e:id` (особое), `p:текст` (к папе), `q:papa` = `yes|no`, `q:bel` = `yaz|lit|both`.

Записи за прошедшие даты и просроченные разовые вещи удаляются при запуске. Поля `always`, `subj`, `papa` в сохранённом состоянии остались от прежних версий и игнорируются.

## 5. Функции

1. **Выбор дня.** Шесть белых клавиш фортепиано, Пн–Сб. До 8:00 в учебный день открывается сегодня, в остальное время завтра; воскресенье пропускается. При возврате в приложение день выставляется заново.
2. **Билет под клавишами.** «в школу к 8:50», название дня, «завтра» или «сегодня», число уроков, время окончания.
3. **Счётчик** «Собрано N из M», кнопка «Снять галочки», сообщение «Всё собрано. Рюкзак готов.».
4. **Особое на день.** Единственное, что ученица добавляет сама. Режимы «Только в этот раз» и «Каждую неделю».
5. **Каждый день.** Дневник, пенал, пропуск.
6. **Карточки уроков** по порядку расписания: номер, время, название, кабинет, вещи. Два одинаковых урока подряд объединяются (хор в субботу).
7. **Белорусский.** В дни с одним белорусским уроком (Пн, Вт, Пт) заранее неизвестно, язык это или литература. Карточка «Белорусский» с выбором «Язык / Литература / Не знаю»; по умолчанию «Не знаю» показывает вещи для обоих.
8. **Суббота: «Едешь к папе?»** При ответе «Да» карточка становится праздничной («Едем к папе! 🎉») и показывает отдельный список.
9. **Мелочи.** «Математика (ура, сегодня матеша!)», «Хор 🔔».
10. **Пасхалка.** Чёрные клавиши играют ноты (до-диез, ре-диез, фа-диез, соль-диез). Четыре по порядку слева направо запускают начало «Лунного света» Дебюсси (общественное достояние) и звёзды. Ноты записаны по памяти и не сверены с нотным текстом.

Светлая и тёмная темы следуют настройке телефона.

## 6. Решения и причины

| Решение | Причина |
|---|---|
| Веб-приложение вместо нативного | Нативное требует Xcode, платного аккаунта Apple и пересборки при каждом изменении |
| GitHub Pages вместо страницы на claude.ai | У ребёнка не может быть аккаунта Claude; нужна работа офлайн и запуск без рамки сайта |
| Списки вещей только в коде | Правка одним пушем доходит до телефона; смена телефона ничего не ломает |
| Режим настроек и запасная копия убраны | Ребёнку пришлось бы пересылать строку кода; постоянные правки идут через отца |
| «Особое на день» оставлено | Разовые вещи появляются накануне, цепочка через отца не успевает |
| Мотивационный блок убран (серия, приз, персонажи, недельная цель) | Награда платит за галочки, а не за собранный рюкзак; каникулы обнуляли серию |
| Прогноз снега убран | Нет источника с часами и количеством; странице запрещено ходить в сеть без ежедневной задачи |
| Домашние задания из Viber не реализованы | База Viber Desktop зашифрована; официальный API не читает группы |

Не предлагать снова без новой вводной: приз и серии, карточку снега, запасную копию через буфер обмена.

## 7. Ограничения

- Персонажей игры Dandy's World и музыку из неё не использовать: чужие права. Собственные рисунки и классика в общественном достоянии допустимы.
- Репозиторий публичный. Не добавлять фамилии, адреса, телефоны, почту. В коде уже есть расписание с кабинетами, вопрос «Едешь к папе?» и имя Мария в одном пункте списка.
- В странице стоит запрет индексации (`noindex`), это просьба к поисковикам, а не защита.
- Звук из веб-страницы на iPhone молчит в беззвучном режиме.
- Веб-приложение не шлёт уведомления. Напоминание живёт в общем списке Apple Reminders; будильник Urgent нужно включать с телефона ученицы, иначе он звонит у создателя.
- Вкладка Safari и значок на домашнем экране хранят данные раздельно.

## 8. Открытые вопросы

1. **Списки вещей по предметам — предположения.** Подтверждены владельцем только: пропуск в «Каждый день», «Тетрадь по специальности», список «к папе». Остальное («Учебник, Тетрадь», форма на физкультуру, хоровая папка, набор для сольфеджио) нужно сверить с ученицей.
2. **Время в билете** — это звонок на урок. Не решено, сдвигать ли его на запас.
3. **Время окончания** считается по последнему уроку сетки. Реальное время специальности может отличаться.
4. **Девиз «better late than ugly».** Показаны три концепта: под названием, штамп на билете, в сообщении «Всё собрано». Рекомендован третий. Выбор не сделан.
5. **Значок человека с красными волосами.** Эмодзи такого нет; предложен собственный рисунок. Не указано, куда его ставить.
6. **Мелодия пасхалки** не проверена на слух.
7. **Физкультура в четверг** помечена в расписании «т/з»; расшифровка не уточнена, в приложении показано как есть.

## 9. Как вести работу

- Отвечать по-русски, вывод первым, без похвалы и пересказа. Показывать, где решение сломается.
- Отделять факт от предположения; непроверенное помечать «уточнить».
- Интерфейс macOS у владельца английский: Documents, Settings, Go to Folder.
- GitHub — обычный `git` в Terminal, аккаунт `iChuvak`. Утилиту `gh` не предлагать.
- Команды для Terminal: шаги через `&&`, файлы в `git add` поимённо, путь проверять заранее. Причина: однажды команда без этих мер начала добавлять в git всю домашнюю папку.
- Если действие нельзя выполнить самому, сказать об этом сразу, до обещаний.
- После каждой правки проверять приложение в браузере на размере iPhone: все шесть дней, обе темы, отсутствие ошибок в консоли.
- После записи файла на Mac сверять, что там лежит новая версия: запись может запаздывать.
- Новые стили называть так, чтобы они не совпали со старыми. Причина: класс `.big` от удалённой кнопки однажды сломал пасхалку.
