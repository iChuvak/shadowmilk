# Собери рюкзак

Веб-приложение для сборов в школу. Ученица выбирает день недели и получает список вещей с галочками.

- Адрес: https://ichuvak.github.io/shadowmilk/
- Репозиторий: https://github.com/iChuvak/shadowmilk
- Папка на Mac: `~/ClaudeCode/shadowmilk`
- Полное описание устройства и принятых решений: [SPEC.md](SPEC.md)

## Как обновить приложение

Вся логика и все данные лежат в одном файле: `index.html`.

1. Измените `index.html` (сами или через Claude, см. раздел ниже).
2. Выложите:

```bash
cd ~/ClaudeCode/shadowmilk && git add index.html && git commit -m "что изменено" && git push
```

3. Через 1–2 минуты откройте адрес приложения и проверьте изменение. Если видна старая версия, обновите страницу с Cmd+Shift+R.
4. На телефоне новая версия подхватывается при следующем открытии приложения с интернетом. Иногда нужно открыть дважды: первый запуск скачивает файл, второй его показывает.

Правила для команд:

- Шаги связаны через `&&`: при ошибке цепочка останавливается.
- В `git add` перечисляйте файлы поимённо. `git add .` не используйте.
- Перед командой убедитесь, что `cd` указывает на папку проекта.

## Что где менять в index.html

Все данные находятся в начале блока `<script>`.

| Что изменить | Где |
|---|---|
| Расписание по дням | `SCHEDULE`: день → список `[номер урока, ключ предмета, кабинет]` |
| Название предмета, эмодзи после названия | `NAMES` |
| Вещи по предмету | `DEFAULTS.subj` |
| Вещи на каждый день | `DEFAULTS.always` |
| Список «Едем к папе» | `DEFAULTS.papa` |
| Время начала уроков | `TIMES` |
| Время окончания уроков | `ENDS` |
| Мелодия пасхалки | функция `blackKey`, массив нот с частотами и длительностями |

Дни в `SCHEDULE`: 1 — понедельник, 6 — суббота.

После правки списков ничего переносить на телефон не нужно: списки вещей приложение всегда берёт из файла.

## Если добавляется новый файл

Иконка, шрифт, картинка: добавьте имя файла в список `FILES` в `sw.js` и увеличьте номер в строке `var CACHE="ryukzak-1"` (например, до `ryukzak-2`). Иначе новый файл не попадёт в офлайн-копию.

## Обновление через Claude

Коротко опишите, что поменять, и дайте Claude прочитать `SPEC.md`.

- Сессия с подключённой папкой `~/ClaudeCode/shadowmilk`: Claude правит `index.html` на Mac, пуш выполняете вы.
- Сессия, запущенная с подключённым репозиторием `iChuvak/shadowmilk`: Claude может выложить изменения сам.

## Установка на iPhone

1. Откройте адрес в Safari.
2. Share → Add to Home Screen.
3. Запускайте только со значка. Вкладка Safari и приложение со значка хранят галочки раздельно.

Проверить ограничения Screen Time: Safari разрешён, сайт `ichuvak.github.io` не заблокирован в Web Content, приложение доступно во время Downtime.

## Если что-то сломалось

- Адрес отдаёт 404: проверьте Settings → Pages в репозитории, Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
- Приложение открывается, но показывает старое: закройте его полностью и откройте дважды с интернетом.
- Пропали галочки или «Особое»: данные хранятся только в телефоне и стираются при удалении значка или очистке данных сайта. Списки вещей при этом не теряются.
- Нужно вернуть прошлую версию: `git log --oneline`, затем `git revert <номер коммита>` и `git push`.
